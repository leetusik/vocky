--font-en -apple-system, BlinkMacSystemFont, system-ui, "Segoe UI", sans-serif no vendored face

A bare system stack — there is no vocky face behind this token. It resolves to whatever the OS supplies, so it renders differently on every machine and its specimen below is not a designed artifact. Korean line-breaking

globals.css sets h1–h6 { word-break: keep-all }. Korean has no inter-word break opportunity by default, so without this a heading breaks mid-word (mid-어절). It is load-bearing for every Korean heading in the app and must survive any type change made at this gate.
