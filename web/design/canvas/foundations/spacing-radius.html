Spacing & Radius

Named section spacing, container widths, the xs breakpoint, and the radius scale — every non-color layout token in web/design/canvas/tokens.css (a 1:1 mirror of web/src/app/globals.css @theme). Bars and boxes derive their size from the token itself, so they re-render if a value changes at the gate. (The base utility scale is Tailwind's 4px step.)

Breakpoints (25% scale) — 1

--breakpoint-xs has no consumer in shipped code. It is declared in globals.css (inherited from hi2vi, where xs: utilities are used), but no vocky component uses an xs: variant. Instead the app hardcodes an arbitrary min-[900px]: at 11 call sites across the shell and list surfaces — a width that is in no token at all. So vocky's one declared breakpoint is unused, and its one real breakpoint is untokenized. Open question for this gate.
